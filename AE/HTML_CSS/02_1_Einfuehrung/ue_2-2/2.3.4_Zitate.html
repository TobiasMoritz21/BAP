< ="http://de.wikipedia.org/wiki/Zitat"> Die Verwendung von Zitaten ist durch das Urheberrecht geregelt und unter bestimmten Voraussetzungen gestattet, ohne dass eine Erlaubnis des Urhebers eingeholt oder diesem eine Vergütung gezahlt werden müsste [...]. Die allgemeine Begründung dafür ist, dass Zitate der kulturellen und wissenschaftlichen Weiterentwicklung einer Gesellschaft dienen [...].
